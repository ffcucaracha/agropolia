# ADR-0001: Modular monolith для MVP

Статус: принято.

Backend разворачивается как один application image с отдельными entrypoint `api` и `worker`. Доменные границы остаются Python-модулями с явными импортами. Выделение в отдельный сервис требует отдельного ADR и причины: SLA, масштабирование, безопасность, lifecycle или технологическая необходимость.
